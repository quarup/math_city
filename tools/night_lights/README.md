# Night lights

Which windows light up on each building sprite at night, and the tool to
get them right (design record: [city_builder.md §12](../../city_builder.md)).

```sh
PY=tools/sprite_pipeline/.venv/bin/python     # needs numpy, opencv, Pillow

$PY tools/night_lights/serve.py               # the review page, http://127.0.0.1:8765
$PY tools/night_lights/detect.py              # re-run the detector (new or changed sprites)
$PY tools/night_lights/build.py               # re-bake every sprite's assets
```

## Reviewing

`serve.py` opens a page with every building sprite shown at night.

- **Toggle** (T): click a region to switch it on or off. Off regions have a
  red outline. Alt-click changes a region between *window* and *glow*.
- **Wand** (W): click a window the detector missed; it grows to the patch
  of similar colour. Raise the tolerance if it stops short, lower it if it
  leaks.
- **Box** (B): drag a window shape. Pick which way the facade runs first
  (╲ ╱ ▭).
- **Window / Glow**: what a new region is. A *window* is relit warm and
  keeps a room's hours; a *glow* (a sign, a lamp, a screen, a ride) keeps
  its own colour and follows the building's closing time.
- D day / night, O outlines, Z zoom, A all on, N all off, ← → previous /
  next, R reviewed and next.

Every change is saved to `overrides.json` and baked into
`assets/buildings/lights.json` and `assets/buildings/lit/<sprite>.png` at
once, so `git diff` is the review and the app picks it up on the next run.
Commit all three.

## Files

| File | What |
|---|---|
| `detect.py` | Finds candidate regions by shape: warm lit panes, dark glass darker than its frame, curtain walls cut along their mullions. Writes `candidates.json`. |
| `candidates.json` | Every candidate with its default on / off. Regenerated by `detect.py`; do not edit. |
| `overrides.json` | What a person changed: switches, kinds, added regions, reviewed flags. The source of truth for decisions. |
| `build.py` | candidates + overrides → `assets/buildings/lights.json` and `assets/buildings/lit/`. |
| `serve.py`, `review.html` | The review page. |
| `nl_common.py` | Shared: the lit-pixel bake and the night preview. |

Never hand-edit `assets/buildings/lit/` or `lights.json`; change the
decision in the review page (or `overrides.json`) and re-bake.

After adding or regenerating a building sprite: run `detect.py <sprite>`,
then review it.
