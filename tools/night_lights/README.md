# Night lights

Which windows light up on each building sprite at night, and the tool to
get them right (design record: [city_builder.md §12](../../city_builder.md)).

```sh
PY=tools/sprite_pipeline/.venv/bin/python     # needs numpy, opencv, Pillow

$PY tools/night_lights/serve.py               # the review page, http://127.0.0.1:8765
$PY tools/night_lights/detect.py              # re-run the detector (new or changed sprites)
$PY tools/night_lights/build.py               # re-bake every sprite's assets
```

## Reviewing

`serve.py` opens a page with every building sprite shown at night. Every
region is a simple polygon: four corners for a plain window, never more
than six.

- **Edit** (E, the default): click a region to select it.
  - Drag a corner to move it; drag inside (or on an edge) to move the
    whole shape.
  - Double-click an edge to add a corner, up to six. Alt-click a corner to
    remove it, down to three.
  - Space switches it on or off, G flips it between *window* and *glow*,
    Delete removes it, Esc deselects.
- **Toggle** (T): click regions on and off quickly. Off regions have a red
  outline.
- **Draw** (P): click each corner of a window (3 to 6). Click the first
  corner again, double-click or press Enter to finish; Esc cancels.
- **Box** (B): drag a window shape. Pick which way its top edge runs first
  (╲ ╱ ▭).
- **Wand** (W): click inside a window the detector missed; it grows to the
  patch of similar colour and becomes a polygon. Raise the tolerance if it
  stops short, lower it if it leaks.
- **Window / Glow**: what a new region is. A *window* is relit warm and
  keeps a room's hours; a *glow* (a sign, a lamp, a screen, a ride) keeps
  its own colour and follows the building's closing time.
- ⌘Z / Ctrl-Z undo, D day / night, O outlines, Z zoom (fit, 2×, 3×, 4×,
  6×), ← → previous / next, R reviewed and next.

Every change is saved to `overrides.json` and baked into
`assets/buildings/lights.json` and `assets/buildings/lit/<sprite>.png` at
once, so `git diff` is the review and the app picks it up on the next run.
Commit all three.

## Files

| File | What |
|---|---|
| `detect.py` | Finds candidate regions by shape: warm lit panes, dark glass darker than its frame, curtain walls cut along their mullions. Each becomes a polygon of at most six corners. Writes `candidates.json`. |
| `candidates.json` | Every candidate with its default on / off. Regenerated by `detect.py`; do not edit. |
| `overrides.json` | What a person changed: switches, kinds, reshaped polygons, added regions, reviewed flags. The source of truth for decisions. Created on the first edit. |
| `build.py` | candidates + overrides → `assets/buildings/lights.json` and `assets/buildings/lit/`. |
| `serve.py`, `review.html` | The review page. |
| `nl_common.py` | Shared: the lit-pixel bake and the night preview. |

Never hand-edit `assets/buildings/lit/` or `lights.json`; change the
decision in the review page (or `overrides.json`) and re-bake.

After adding or regenerating a building sprite: run `detect.py <sprite>`,
then review it.
